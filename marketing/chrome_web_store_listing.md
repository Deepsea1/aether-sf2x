🛡️ AETHER — THE TRUTH LAYER FOR AI
Verify AI responses in real-time across ChatGPT, Claude, Gemini, Perplexity, and more. Stop guessing if AI output is true—get instant trust scores and factual corrections powered by a 3-model tribunal.

--------------------------------------------------

⚠️ THE PROBLEM: UP TO 86% OF UNVERIFIED AI OUTPUTS CONTAIN HALLUCINATIONS

Generative AI models sound completely confident even when they are entirely wrong. Studies show unverified AI outputs can have hallucination rates as high as 86% in specialized domain queries, legal references, technical documentation, financial stats, and code logic. 

Standard LLMs suffer from critical flaws:
• They fabricate citations, quotes, and non-existent regulations.
• They generate plausible-sounding math, reasoning, and code bugs.
• They present false premises as absolute facts.
• They lack real-time cross-verification against independent sources.

Relying on raw AI output for work, research, coding, or legal analysis puts your professional credibility and accuracy at risk.

--------------------------------------------------

⚖️ THE SOLUTION: 3-MODEL TRIBUNAL VERIFICATION

Aether introduces "The Truth Layer for AI"—a real-time verification engine that sits directly inside your browser. Instead of trusting a single AI model's output, Aether routes response claims through an independent, multi-model consensus tribunal.

When you click "Verify with Aether", three distinct frontier models instantly cross-examine the AI response:
1. Claim Decomposition & Extraction: Isolates factual statements, statistics, quotes, and citations.
2. Cross-Model Adversarial Audit: Each model in the tribunal independently evaluates truthfulness, flags logical fallacies, and checks against reference corpora.
3. Consensus Verdict & Scoring: Synthesizes a unified Trust Score (0-100%), highlights hallucinated sentences, and provides verified corrections.

--------------------------------------------------

⚡ HOW IT WORKS

1. Generate any response on ChatGPT, Claude, Gemini, Perplexity, Copilot, Poe, or Character.ai.
2. Click the native "Verify with Aether" button injected directly beneath the AI response.
3. Watch the 3-Model Tribunal analyze the response in seconds.
4. Review your instant Trust Score (e.g., 91/100 certified vs 28/100 high risk).
5. Inspect line-by-line breakdown: highlighted hallucinations, verified true statements, missing context, and exact corrected facts.

--------------------------------------------------

🌟 KEY FEATURES

• Accurate Fact Corrections: Provides corrected numbers, working code snippets, and verified references when errors are detected.
• Multi-Platform Support: One extension works across all major AI chat tools.
• Custom API Key Support: Bring your own key or connect to Aether's cloud verification engine.

🔒 PRIVACY & DATA PROTECTION SUMMARY

Your privacy and security are fundamental to Aether:

## 6. Privacy Practices Summary
*(Required metadata disclosures for Chrome Web Store Developer Dashboard Privacy tab)*

### Single-Purpose Declaration
The extension's sole purpose is to verify the factual accuracy and reliability of AI-generated response text via multi-model consensus verification upon explicit user action.

### Host Permissions & Permissions Rationale

| Permission / Access | Specific Purpose | Justification |
| :--- | :--- | :--- |
| `storage` | Store extension settings and user API keys locally | Essential for saving user preferences and custom credentials locally without external cookie tracking. |
| `host_permissions` (`https://aether.sf2x.com/*`) | Send verification requests to Aether API | Necessary for transmitting the selected AI text to the multi-model tribunal service and receiving trust scores and corrections. |
| `content_scripts` (`chatgpt.com/*`, `claude.ai/*`, `gemini.google.com/*`, `copilot.microsoft.com/*`, `perplexity.ai/*`, `poe.com/*`, `character.ai/*`) | Detect AI responses and inject the "Verify" UI | Strictly limited to major AI assistant domains to allow users to trigger verification directly within their chat workflow. |

### Data Handling Disclosures
1. **Personal Information**: None collected, stored, or transmitted.
2. **Health / Financial Information**: None collected.
3. **Authentication Data**: User API keys are stored locally in `chrome.storage.local` and never transmitted to unauthorized third parties.
4. **User Content**: Only the specific text block selected by clicking "Verify with Aether" is processed. Text is processed ephemerally for verification and is never sold or used for AI model training.
5. **Web History**: No web history, page URLs outside supported AI chats, or general browsing data is ever accessed or logged.
