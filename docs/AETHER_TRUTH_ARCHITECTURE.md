# Aether Truth Architecture

## Canonical decision dimensions

Every material factual response must preserve these independent dimensions:

```text
truth_status
evidence_basis
proof_level
integrity_status
action_authorization
```

Neither a signature, model score, model consensus, citation count, nor source
count may substitute for any of them.

## Required serving path

```text
authorization + tenant scope
-> claim compiler
-> policy resolver
-> secure retrieval and source identity
-> evidence normalization and deterministic tools
-> independent critic/falsifier
-> Truth Gate
-> renderer
-> warrant/ledger
-> correction, revocation, revalidation, and outcome loop
```

Failures at a policy-required stage produce `UNKNOWN`,
`INSUFFICIENT_EVIDENCE`, `STALE`, or `CONTESTED` as applicable. They never
produce a stronger factual result.

## SF2X boundary

Aether owns factual evidence, policy decisions, warrants, and corrections.
SF2X may create archetypal, creative, hypothetical, and personal-meaning work,
but it cannot force that material into factual truth. Action authorization is a
separate gate even when Aether reports `VERIFIED`.
